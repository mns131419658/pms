# 專案管理系統

裝修工程 / 設計 / 營造公司適用的內部管理系統，在自己的電腦上執行，資料不外傳。

**第一次使用請先看 [首次設定指南.md](首次設定指南.md)。**

## 快速開始

```bash
npm start          # 或雙擊 啟動系統.bat
```

開啟 <http://localhost:3000/>，預設帳號 `A0000`、密碼 `0000`（**登入後請立刻變更**）。

需要 Node.js 18 以上：`winget install OpenJS.NodeJS.LTS`

## 功能

| 模組 | 內容 |
|---|---|
| 客戶資料 | 新增／修改／刪除、關鍵字查詢、CSV 匯入與範本下載 |
| 廠商資料 | 同上，營業項目可複選、結帳方式 |
| 報價資料 | 明細子表單、廠商報價／利潤／利潤%、5% 稅金、複製、複製改版、匯出 PDF |
| 專案管理 | 甘特圖進度追蹤、追加減帳（變更單）、專案日誌、結案附件、關聯的應收應付與維修單 |
| 維修工單 | 報修 → 派工 → 完修 |
| 應收款項 | 稅額自動 5%、保留款、發票與作廢、請款單 PDF |
| 應付款項 | 憑證類別扣抵規則、所得類別與扣繳、二代健保、支票管理、付款憑証 PDF、AI 發票辨識 |
| 會計維護 | 應收應付收付款登錄、員工薪資（本月發薪、獎金、勞健保與所得稅試算） |
| 公司報表 | 營收結算（損益表）、專案獲利、帳齡分析、營業稅 401、扣繳彙總，皆可匯出 CSV |
| 帳號管理 | 八種功能權限、帳號鎖定與解鎖、薪資設定 |
| 項目維護 | 八組下拉清單自行增刪，不需改程式 |
| 操作紀錄 | 最近 1000 筆寫入動作（不含查詢與密碼內容） |
| 系統還原 | 從備份檔還原，執行前自動下載目前資料的備份 |

首頁另有待辦提醒：應收應付逾期與將到期、支票到期、專案階段逾期、驗收中、保固將到期。

## 資料存放

| 路徑 | 內容 |
|---|---|
| `data/db.json` | 全部資料（15 張表）。**備份＝複製整個 `data` 資料夾** |
| `data/files/` | 結案附件實體檔，依專案編號分資料夾 |
| `data/session-secret.txt` | 登入簽章金鑰，首次啟動自動產生 |

不需要安裝資料庫伺服器，也不需要設定連線。

## 環境變數（皆可省略）

| 變數 | 預設 | 說明 |
|---|---|---|
| `PORT` | `3000` | 服務埠號 |
| `PMS_DATA_DIR` | `./data` | 資料存放位置 |
| `ADMIN_ID` / `ADMIN_PASSWORD` / `ADMIN_NAME` | `A0000` / `0000` / 系統管理員 | 僅在資料庫**完全沒有帳號**時，用於建立第一個管理者 |
| `SESSION_SECRET` | 自動產生 | 不設定則首次啟動產生亂數並存檔 |
| `ANTHROPIC_API_KEY` | 無 | AI 發票辨識功能 |

## 技術

Node.js + Express，資料存單一 JSON 檔（寫入採 tmp + rename 原子替換），
密碼以 scrypt 雜湊，登入採 session cookie（8 小時逾時），連續錯誤 5 次鎖定帳號。

**除 `express` 與 `express-session` 外沒有其他相依套件，不含任何原生模組**，
整個資料夾可直接複製或壓縮搬到別台電腦（含 Mac / Linux）執行。

## 安全性提醒

這套系統設計為**公司內部網路使用**，沒有 HTTPS 加密，也未針對公開網際網路做防護。
請勿直接架設在對外的伺服器上。

`data/db.json` 內含所有營運資料與密碼雜湊，備份檔請比照機密文件保管。
